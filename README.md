# Ecosphere-Footprint

Ecosphere is a small, browser-based environmental footprint experience. Start at `homepage.html`, answer the ten questions, and explore a scrollable cascade from the atmosphere to the ocean floor.

## Run locally

Open `homepage.html` in a browser. No build step or server is required. The questionnaire score is saved in the browser's local storage so the cascade page can personalize its summary and impact notes.

## About the score

Each answer contributes 0–3 points, for a total from 0 to 30. The score is a lightweight reflection tool—not a scientific footprint calculation or a judgment of individual behavior.
